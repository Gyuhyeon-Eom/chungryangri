## ⚠️ 최우선 리스크 — 생활인구 데이터 종료 공지

집계구/행정동 단위 생활인구(OA-14979, OA-14991, OA-14978)에 **2026-07-31자로 기존 데이터 생산을 종료하고 250m 국가표준격자로 전환**한다는 공지가 게시되어 있습니다.

- OA-14979 파일 목록에는 2026.08 파일이 아직 존재 → **공지와 실제 배포가 불일치**
- 대체될 250m 격자 생활인구는 KT 협약상 **서울 빅데이터캠퍼스 내에서만** 제한 이용되며, 일반 공개 여부 미확인
- **대응**: 과거 파일(2018.03~2026.08, 월별 약 115개)을 즉시 일괄 백업
